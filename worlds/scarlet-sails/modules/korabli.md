# korabli — корабли мира (движок 2)

## «Секрет» снаружи

Белый трёхмачтовый галиот собран в сцене из элементов на невидимом якоре у её ватерлинии: борта (семь плит — видна
каждая грань, свет ложится по повороту), палуба и ют (плоскости `walk`: на них стоят и ходят), карточка вдоль киля
(мачты, бушприт, штаги, вымпел на ветру, фонарь), карточка поперёк у фок- и грот-мачты (мачта и реи), и паруса —
каждый свой элемент, нарисован один раз, двигает его шейдер парусины мира. Паруса просвечивают (`translucent`).

```
node tools/korabl.js <папка сцены> [id якоря = ship] [брасопка, градусы = 35]
```
— пишет элементы `<id>_side`, `_side_port`, `_bow`, `_bow_port`, `_quarter`, `_quarter_port`, `_transom`, `_deck`,
`_poop`, `_break`, `_rig`, `_fore`, `_fore_course`, `_fore_top`, `_fore_tg`, `_main`, `_main_course`, `_main_top`,
`_main_tg`, `_jib`, `_jib_outer`, `_spanker` сразу после якоря (их файлы — строка модуля; шейдер парусов —
`tools/korabl-cloth.glsl`). Якорь — сцены: если его нет, создаётся. После правки модуля или шейдера запустить снова.

```json
{ "id": "ship", "name": "«Секрет»", "unseen": true, "across": 60, "distance": 260, "elevation": -0.1, "facing": 0,
  "place": { "across": "ship_across", "distance": "ship_distance", "facing": "ship_facing", "tilt": "ship_roll" } }
```

- Якорь стоит на воде (`elevation` — уровень моря). Оси корабля (как `on` ставит вещи): `across` — вперёд вдоль киля
  (нос +17, корма −16.5), `distance` — к левому борту (борт ±3.7), `elevation` — вверх от воды. `facing` якоря: 0 — носом
  влево, к нам левым бортом; 180 — носом вправо; 270 — носом на нас; 90 — кормой к нам.
- Качка — `tilt` якоря по ключу: в `script.js` `scene.kit.korabli.swell(scene, 'ship_roll', 4.2, 1.6)` (каждые 4.2 с на
  другой борт, до 1.6°).
- Люди на борту: `"on": "ship"`, место в осях корабля, высота — палубы: шкафут `SECRET.deck` (2.4 м), ют `SECRET.poop`
  (3.8 м, корма до X −8.5). Идут и стоят в её раме, остаются прямыми в качку.
- Ключи сцены, которые читают её `animate` (нет ключа — паруса подняты, белые, полные; огни не горят):
  `sails_set` 0…1 — убраны → подняты, по очереди (нижние, марсели, брамсели; реи марселей и брамселей идут вверх);
  `sails` 0…1 — белые → алые; `luff` 0…1 — заполаскивают; `lanterns` 0…1 — фонарь на штаге, кормовой фонарь, окна
  каюты; `<id>_spark` 0…1 — искра парусов издали (дальше мили корабль — светящаяся точка, белая или алая; без ключа
  горит).
- Точки: `<id>_rig#ship` (середина, полвысоты), `#masthead`, `#bow`, `#stern`, `#deck`, `#wheel`, `#ladder` (у воды,
  посередине борта); `<id>_side#ladder`, `<id>_transom#stern`. Якорь `<id>` годится как цель камеры и взгляда.
- Свет: фонари — свечения `<id>_rig#lamp`, `<id>_transom#stern_lamp`; сцена может взять их в `lights` (`of`).

## Парусина — один шейдер на мир

`tools/korabl-cloth.glsl`: парус нарисован раз, поднятым, белым; шейдер ставит его насколько `set` (убран — валик у
рея; `rise` 1 — растёт от нижней шкаторины вверх, 0 — падает от рея), красит в алый по светам и тёмным рисунка
(`scarlet`), ведёт по ткани длинные складки ветра со светом на гребнях (`wind`, порывами) и трясёт, когда парус
заполаскивает (`luff`). Uniforms: `head`, `foot` (y верхней и нижней шкаторин в единицах рисунка), `rise`, `seed`
(свои у каждого паруса), `set`, `scarlet`, `luff`, `wind` (их ставит `animate`).

Свои паруса сцены (палуба): рисунок — `korabli.squareSail(g, c, { yard, foot, w0, w1 }, seed, side?, lap?)` (мачта в x 0, высоты вверх; `side` −1 | 1 — только
эта половина паруса, заходит за мачту на `lap` = 0.6 м, ткань лежит как у целого — половины сходятся в одно полотно),
`korabli.alongSail(g, c, [[X, высота], …])` или свой контур + `korabli.cloth(g, c, [l, t, r, b], { seams, seed })` (ткань
по уже проведённому контуру; `whole` — прямоугольник целого паруса, когда красится его часть: тело, свет на пузе, тень под реем, швы, заплаты «Ансельма»; `c` — цвета корабля,
`SHIPS.secret`); шейдер и uniforms —

```
node tools/korabl.js <папка> cloth <id>:<head>:<foot>:<rise>:<seed> …
```
`animate` паруса ставит `set`, `scarlet`, `luff`, `wind` (`e.uniform`); `korabli.setOf(sails_set, order)` — насколько
поднят парус по очереди. Элементу паруса — `"translucent": 0.55`.

## Что ещё

- `SHIPS` — `{ secret, anselm }`: цвета обоих кораблей днём — `hull`, `deck`, `seam`, `bulwark`, `rail`, `spar`, `rig`,
  `cloth`, `patch` (заплаты «Ансельма»; у «Секрета» `null`).
- `SECRET` — размеры «Секрета» (нос, корма, борт, палубы, мачты); `SAILS` — её паруса (рей, нижняя шкаторина, ширины,
  очередь); `GALLIOT` — `{ length: 34, height: 29 }`.
- `toy(g, e)` — яхта Ассоль на воде или на полке (киль в y 0, 0.34 м): белый корпус, алые паруса; точка `toy`. Слоёв не делает.
- `reeds(g, e)` — девять стеблей камыша из воды перед яхтой (как когда она застряла), от y 0, вокруг x 0. Слоёв не
  делает: сцена рисует их в своём слое — `e.layer("reeds", { box: [-0.24, -0.34, 0.24, 0.02] }, (g) => kit.korabli.reeds(g, e))` —
  и ставит его альфу (ключ `reeds`) в `animate`.
- `skiff(g, e)` — шлюпка сбоку, носом влево, от ватерлинии (4.6 м): тёмный корпус, светлые планширь и пояс; люди в ней —
  `"on": "skiff"`. Точки `skiff` (середина, у воды), `bow`, `seat1` (кормовая банка), `seat2` (носовая). Слоёв не делает.
- `far(g, e)` — рыбачья лодка вдали, носом влево, от ватерлинии (6 м): низкий корпус, мачта, на ней фонарь — свечение
  `light` в полную силу (`animate` элемента: `e.glow("light", k)`). Слоёв не делает.
- `steamer(g, e, colours?)` — почтовый пароход сбоку, носом влево, от ватерлинии; нарисован раз, без дыма; точки
  `funnel` (верх трубы) и `steamer`; топовый огонь на грот-мачте — свечение `light` в полную силу (`e.glow("light", k)`). Слоёв не делает. `STEAMER` — `{ length: 50, height: 22, funnel: [0, -15.5] }`. Дым — частицы сцены:
  `{ "id": "steamer_smoke", "particles": { …korabli.SMOKE, "at": "steamer#funnel" } }` (`SMOKE` — поля для JSON).
- `lantern(g, e, name)` — корабельный фонарь (основание в 0, 0), свечение `name` в полную силу: `animate` элемента
  даёт `e.glow(name, k)`.
- `swell(scene, key, every, most)` — качка (выше).

Нет больше: `galliot(g, colours)` (плоский рисунок корабля), дым в `steamer` по `e.t`.
