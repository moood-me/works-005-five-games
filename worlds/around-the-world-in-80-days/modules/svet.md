# svet

Цвета мира и час Лондона — одни для всех его сцен: Пэлл-Мэлл за окнами клуба и Сэвил-Роу — один город в
один час. Всё рисуется один раз, в дневных цветах; час — свет сцены: её `looks` на ключе часа (`ambient`,
`ambientColor`, `hazeColor`, …). Модуль даёт цвета для того, что свет сделать не может, — и газ.

- `mixc(a, b, u)` — цвет между a и b (`#rrggbb` или `[r, g, b]`), u 0…1 → `[r, g, b]`; `rgba(c, a)` — для
  `fillStyle`; `css(c)` — `#rrggbb` (что берут `e.light`, `lights`, `looks`); `lin(c, out?)` — цвет для шейдера,
  линейный 0…1 (`out` — свой массив `animate`, чтобы не делать новый каждый кадр).
- `glow(g, x, y, r, c, a, sy)` — мягкое пятно, нарисованное: радиальный градиент цвета c (непрозрачность a) в ничто,
  сжатый sy раз по высоте. Свечение лампы и ореол в воздухе — движка (`e.light`, `light.hazeGlow`), их не рисовать.
- `london(night)` — цвета тумана в час `night` (0 — серый день, 0.5 — сумерки, газ зажигают, 1 — ночь) →
  `{ night, high, low, gas }`: туман вверху и низко над улицей, газ 0…1. Небо не освещается светом сцены — его туман
  нарисован раз (градиент как доля «верх → низ»), цвета даёт его шейдеру `animate`:
  ```js
  // animate неба: uniforms high_r, high_g, high_b, low_r, low_g, low_b
  const A = e.kit.svet.london(e.state.day), m = e.mem, h = e.kit.svet.lin(A.high, m.h ??= [0, 0, 0]), l = e.kit.svet.lin(A.low, m.l ??= [0, 0, 0]);
  e.uniform('high_r', h[0]); …
  ```
- `gas(night)` — насколько горит газ (0…1) в этот час: `animate` фонаря — `e.glow('lamp1', e.kit.svet.gas(e.state.day))`.
- `gasLamp(g, e, name)` — газовый фонарь, его основание в (0, 0): тонкий чугунный столб, стеклянный шар, его пламя —
  `e.light` элемента `e` (имя `name`, если дано: `lamps#lamp1`) в полную силу газа; час ставит `animate` (`gas`;
  `e.glow` гасит и свет, взятый в `lights` с `of`). Ореол в тумане — `hazeGlow`. Нарисован в дневных цветах: вечер
  делает свет сцены.

В клубе ключ часа называется `day`, на Сэвил-Роу — `night`; значения одни.
