# Плёнка — служебная сцена между главами

Темнота будки; по ней горизонтально идёт кинолента, подсвеченная сзади лампой проектора (лампа — справа внизу средних
4:3, её точка `lamp#lamp`: игра предлагает её нажать). Титул главы — в одном большом кадре ленты; после главы — карта
её выборов кадрами; после эпилога — вся партия тремя лентами. Без музыки. Устройство — как у «Дали» «Алых парусов v3»
(раскладка по измеренным словам в `lib.js`, рисунок раз на карту, проявление — шейдером).

## Состояние

- `chapter_number`, `chapter_title` — строки; обе пустые и без карты — самое начало: только лампа в темноте.
- `map` — `null`: только титул, номер и название в большом кадре 0.46 высоты кадра посередине. Иначе строки
  `[{title, weight '⚑'|'~', options: [{label, state}]}]`: строка — кадр, разрезанный по вариантам на части; `chosen` —
  часть светится тёплым (лампа сквозь плёнку, светит — `emission`), подпись тёмным по свету; `open` — тёмная, подпись
  едва видна; `unseen` — чёрная без слова. Вопрос строки — над кадром светлым («белое старой плёнки»). ⚑ — кадр 0.3
  высоты кадра, ~ — 0.2 (при тесноте — мельче вместе). Кадр 4:3 — шире (до 2.4:1), где ленте хватает места: подписям
  частей нужна ширина. Если подписи частей не встают даже так (шрифт не мельче 0.045 высоты кадра), кадр показывает
  выбранный вариант крупно поверх 3/4 кадра, остальные — тёмной полосой по низу кадра без слов («свёрнутый» кадр).
  До пяти строк — одна лента; если в одной ленте кадры сворачиваются, а в двух нет — две (карта главы IV с подписями
  встаёт в две ленты 2 + 2). Больше пяти — вся партия: три ленты 4 + 3 + 3, над кадром только номер главы («IV»,
  «Финал»), кадры свёрнуты (выбранный крупно); последняя лента короче и не заходит в угол лампы. Заголовок карты —
  номер и название в одну строку наверху (y 0.095, под шапкой сайта).
- `reveal` 0…1 — первая треть: лента въезжает справа в свет; дальше кадры проявляются по очереди (порядок строк),
  вместе со своими вопросами; заголовок и большой кадр — первыми. Игра ведёт 0 → 1 за 3.5 с титула, 2.5 + 1.2 с на
  строку карты.
- `lamp` 0…1 — яркость лампы (и света сквозь кадры).

## Устройство

Все три элемента — небо (сцена 16:9, высоты кадра), `camera` `picture`.
- `dark` — темнота, тёплый воздух у лампы и по линии ленты; рисуется раз.
- `film` — лента; рисуется раз на карту (читает `map`, `chapter_*`, не `reveal`): основа — свечение вокруг
  светящихся частей (шейдер делает его светом), слой 1 — ленты (основа, перфорация в свете лампы, непроявленные кадры
  вдоль всей ленты), 2 — что показывают кадры и все слова, 3 — порядок проявления (серым; не виден). `film.wgsl` сдвигает
  ленту (`slide`, `span`) и проявляет кадры по `develop` против их порядка; `film.animate.js` берёт их из `reveal`
  (`lib.slide`, `lib.develop`).
- `lamp` — корпус фонаря, линза светится (слои: корпус, ореол, линза); дышит; `lamp` — яркость. Точка `lamp#lamp`
  (линза: x = середина + 0.53, y 0.87 — в средних 4:3, не ближе 0.08 к краям).

Шрифт: `"Cormorant Garamond", Georgia, serif`, курсив — **в рисунке сцены веб-шрифтов нет** (рисунок не загружает
шрифты страницы): где Cormorant Garamond не установлен, буквы — Georgia. Размеры — доли высоты кадра, не мельче 0.045.

Показ (`showcase.js`): самое начало, титул главы I, карта главы IV, вся партия.
