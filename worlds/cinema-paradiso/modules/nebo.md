# nebo — небо Джанкальдо

Одно небо на все сцены мира (решение координатора 2026-10-15: небо «Пристани» opus поднято в модуль мира вместо неба
«Алых парусов v3» — у того нет прохладного сиреневого 1988 года рядом с тёплой ночью прошлого). Рисунок раз на тон,
звёзды — слой, шейдер мира делает их мерцающими.

```js
// lib.js сцены
const SKY = { horizon: 0.55, round: true, moon: 7, coast: [[28, 112, 0.045, 3], [48, 140, 0.026, 7]], villages: [40, 100, 9], glow: -50 };
// elements/sky.js
e.kit.nebo.sky(g, e, e.lib.SKY);
```
`node tools/nebo-sky.js <папка сцены>` — пишет `elements/sky.wgsl` (из `tools/nebo-sky.wgsl`). Шейдер правится только
в `tools/`.

**Тон** — из `hour` и `era` сцены (`nebo.tone(hour, era)`): прошлое — `night` (hour ≥ 0.84 или < 0.22: тёплая
сицилийская ночь, звёзды, луна над морем), `dusk` (0.6…0.84: заря на северо-западе), `dawn` (0.22…0.6: бледное золото
на востоке); настоящее (`era` `now`) — `evening` (прохладный сиреневый вечер 1988-го), `morning` (серое стальное утро,
звёзд нет). Небо перерисовывается только при смене тона.

`SKY`: `horizon` — линия глаз (как `"horizon"` сцены); `round` — небо кругом (`roam`, `around`: прямо — `e.aspect/2`),
`false` — небо сцены; `moon` — азимут луны в градусах от «прямо» (`null` — нет); `coast` — дальние берега `[от°, до°,
высота, seed]`; `villages` — `[от°, до°, n]` огоньки на берегу ночью; `glow` — азимут зари в сумерки (рассвет — напротив).

Точки: `sky#disc` (луна; свет сцены `{"id": "moon", "from": "sky#disc"}`). `nebo.pane(g, x0, y0, x1, y1, hour, era,
anim)` — то же небо плоской картинкой в окне комнаты (окошко будки, окно вагона). `nebo.tone`, `nebo.PAL` — для свечения
и `looks` сцены.

Свет часа — `light.looks` самой сцены (у каждой свои: ночь, сумерки, `now`).
