# 2026-10-14 — сценарии четырёх игр по драмам

Ветка `drama-games-scripts`. Только документы: `docs/drama-games/<игра>/`.

Из `pavel-zhur/rpg:docs/backlog/drama-games.md` выбраны четыре игры с разным миром и настроением («Остаток дня», «Дама с собачкой»,
«Парадизо», «Старший сын»; запасные были — «Вино из одуванчиков», «Уве», «Консервный ряд», «Осенний марафон»,
«Правила виноделов»; отказов не было). Работа шла по `moood-me/moood:docs/writing/2026-10-13-scenarij-igry.md`:

1. Каждый сценарий написал свой агент (Opus, среднее усилие), друг друга они не видели; образец — готовый сценарий
   «Алых парусов».
2. Каждый прочитали три независимых читателя (логика, реальность, принципы), каждый — только чтением.
3. Автор закрыл все находки одной правкой и заполнил таблицу «замечание → где закрыто».

Что нашли читатели: длина везде меньше обещанных 35–40 минут (после честного пересчёта 18–28); у всех
геометрия кадров не держала правило «говорящий — четверть кадра»; один блокер в «Старшем сыне» (ключ `box` с двумя
смыслами); модули «Алых парусов» написаны для движка 2 — `beats` для движка 3 взят из «Вокруг света v3», шейдер неба
`nebo` надо переписать на WGSL; у одной из центральных развилок в «Парадизо» была безопасная линия — теперь у правды
есть цена.

Сбой по дороге: на половине чтений кончился недельный лимит, и одиннадцать читателей оборвались; пять отчётов были
дописаны, остальные семь запущены заново.

Не сделано: сцены, картинки, голоса; вопросы владельцу (в `work.md` каждой игры, у каждого запасной ход).
